# V1.2 系 設計案

V1.1（EOD）で配線が成立しなかったため、部品構成を変えた6案をプロジェクトとして複製したもの。
回路の中身以外（基板外形・層構成・ネットクラス・部品ライブラリ）は全案共通。

## 命名規則

| 位置 | 記号 | 意味 |
|---|---|---|
| 接頭 | なし | エンコーダのバッファを廃止 |
| 接頭 | `b` | バッファを 0Ω抵抗からソルダージャンパ（既定開放）に変更 |
| 接頭 | `fb` | バッファを強制有効（選択用の 0Ω抵抗を廃止） |
| 接尾 | `cmp` | QI 拡張ヘッダ J8 / J9 あり |
| 接尾 | なし | QI 拡張ヘッダ J8 / J9 なし |
| 例外 | `org` | V1.1 のまま（バッファ + 0Ω選択式 + QI） |

## 一覧

| 案 | バッファ | QI | 部品 | ネット | ERC | エラー |
|---|---|---|---|---|---|---|
| `V1.2org`  | 0Ω選択式 | あり | 71 | 63 | 29 | 0 |
| `V1.2bcmp` | ジャンパ式 | あり | 71 | 63 | 29 | 0 |
| `V1.2b`    | ジャンパ式 | なし | 74 | 63 | 29 | 0 |
| `V1.2fb`   | 強制有効 | なし | 62 | 63 | 29 | 0 |
| `V1.2cmp`  | なし | あり | 51 | 51 | 29 | 0 |
| `V1.2`     | なし | なし | 54 | 51 | 29 | 0 |

ERC の29件は全て警告。意図的なネットエイリアス28件と、J1 のキャッシュシンボル差異1件。

バッファなし案（`V1.2cmp` / `V1.2`）は `ENC*_BUF` ネットを `ENC*` に統合したためネット数が 51 に減る。
QI なし案は J8 / J9 の削除で単ピンになったネットに TP8〜TP12 を追加している。

## 開発ライン

**`V1.2cmp`**（バッファなし・QIあり）で配線を進める。

## 共通仕様

- U6 = ESP32-S3-WROOM-1-**N16R8**
  - Octal SPI PSRAM が IO35 / IO36 / IO37 を占有するため、この3本は使用不可
  - QIあり案では J9 の 11 / 12 / 13 番ピンが死にピン
  - QIなし案では TP9 / TP10 / TP11 が死にピン
  - 周囲温度 -40〜65℃（PSRAM ECC 有効時は 85℃、容量 1/16 減）
- CAN 終端は R20（120Ω）+ J16（ジャンパ）の直列で CAN_H - CAN_L 間
- 各プロジェクトは `lib/` と `fp-lib-table` / `sym-lib-table` を自前で持つ自己完結構成

## 既知の課題

- 全案とも基板が回路図と未同期。Pcbnew の「回路図から基板を更新」が必要
- 基板は V1.1 の配線（475セグメント / 89ビア）をそのまま継承しているため配線はやり直し
- J1 に `lib_symbol_mismatch` 警告が残る
